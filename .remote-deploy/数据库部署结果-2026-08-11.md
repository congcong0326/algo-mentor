| --- | --- |
| 软件版本 | Ubuntu 官方 `postgresql-16` / `postgresql-client-16`，`16.14-0ubuntu0.24.04.1`。 |
| 集群与服务 | `16/main`，`postgresql@16-main` 已启用并处于 `active`。 |
| 数据目录 | `/data/postgresql/16/main`，由 `postgres:postgres` 管理。 |
| 监听 | `127.0.0.1:5432`、`192.168.10.121:5432`；未监听全部接口或 IPv6。 |
| 认证 | `password_encryption = scram-sha-256`，`ssl = off`（受控开发内网约定）。 |
| 资源参数 | `max_connections=200`、`shared_buffers=3GB`、`effective_cache_size=7GB`、`work_mem=4MB`、`maintenance_work_mem=512MB`、`autovacuum_work_mem=256MB`。 |

| 运行时凭据 | 已生成随机密码并保存于 `leetmentor-dev:/etc/algo-mentor/database.env`；该目录为 `0750 root:algo-mentor`，文件为 `0640 root:algo-mentor`，仅计划服务账户组和 root 可读。密码未写入仓库、本文档或命令历史。 |
