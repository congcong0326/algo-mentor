# 原始参考资料

这里存放编写知识库卡片时查阅的本地资料，不会导入为卡片或文章；正式内容只从 `.node` 目录扫描。资料仓库及网页快照目录被 Git 忽略，本文件保留在版本库中。

| 本地目录 | 来源 | 用途 |
| --- | --- | --- |
| `JavaGuide/` | [Snailclimb/JavaGuide](https://github.com/Snailclimb/JavaGuide) | 检查 Java 主题和常见问题的覆盖 |
| `toBeBetterJavaer/` | [itwanger/toBeBetterJavaer](https://github.com/itwanger/toBeBetterJavaer) | 参考中文教学组织与示例 |
| `OnJava8/` | [OnJava8/OnJava8](https://github.com/OnJava8/OnJava8) | 参考概念讲解与章节递进，具体结论需按 Java 17 核对 |
| `official/` | Java 17 规范、API 与 Dev.java 的本地抽样页面 | 核对语言和 API 契约；该目录不是 Git 仓库 |

当前三份克隆的固定提交、已查阅路径和官方页面快照说明见 [Java 基础参考资料与快照](../../docs/java-fundamentals-pilot/sources.md)。编写卡片时记录具体资料路径或固定版本链接，并用官方文档核对有版本差异的结论。
