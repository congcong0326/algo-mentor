# 编写知识卡片

首次制卡时读取 [维护手册](../../README.md) 中的卡片格式与元数据规则，按其格式编辑正式 `.node` 目录中的 `.card.md` 文件。同一会话已读取且未变化的规范无需重复读取。

以主题 README 的版本和范围为准，只加载当前问题需要的资料。历史调研记录不是制卡必读材料，仅在调整主题范围、追溯来源或解决资料冲突时查阅相关段落；事实核验按需读取相关权威资料，不沿来源链接递归通读。

一张卡片围绕一个可独立评价的问题。标题来自文件名，身份来自维护者指定的 slug；移动、纠错和改名保留 slug，复制成新问题使用新 slug。

先给能直接回答问题的核心回答，再用二级标题展开解释。详细部分按知识需要自由组织，不补无意义的空章节。关联引用使用已存在卡片的 slug，前置关系不能成环。

日常制卡只编辑并审阅内容，不主动运行校验工具或导入。校验统一留到导入环节，用户明确要求时可单独执行根目录 `make knowledge-validate`。只有当前任务包含导入时才执行 `make knowledge-import`，该命令已包含校验；不要把本技能目录或参考资料目录转换成大纲。
