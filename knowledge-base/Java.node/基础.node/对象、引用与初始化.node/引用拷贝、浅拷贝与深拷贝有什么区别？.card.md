引用拷贝只是复制引用值，两个变量仍指向同一个对象。浅拷贝会创建新的外层对象，但其中的引用字段仍指向原来的内部对象。深拷贝则在需要隔离的范围内继续复制内部可变对象，使修改副本的这些状态不会影响原对象。

区分三者，要看外层对象和内部对象分别是否共享。深拷贝的范围需事先确定；像 `String` 这样的不可变对象通常可以共享。

## 用可变元素观察三种结果

```java
StringBuilder[] original = {new StringBuilder("A")};
StringBuilder[] alias = original;                         // 引用拷贝
StringBuilder[] shallow = original.clone();              // 浅拷贝
StringBuilder[] deep = {new StringBuilder(original[0])}; // 深拷贝这个元素

original[0].append("B");
System.out.println(alias[0]);   // AB
System.out.println(shallow[0]); // AB
System.out.println(deep[0]);    // A

original[0] = new StringBuilder("C");
System.out.println(alias[0]);   // C
System.out.println(shallow[0]); // AB
```

`alias` 与 `original` 是同一个数组，因此替换数组元素会同时影响两者。`shallow` 是新数组，所以替换原数组的元素不会改变它；但两个数组原先指向同一个 `StringBuilder`，修改该对象时仍会相互影响。`deep` 连可变元素也新建了，因此这次对原元素的修改不会传到副本。

## 深拷贝要明确隔离哪些状态

引用数组的 `clone()` 或 `new ArrayList<>(oldList)` 会新建容器，但只复制元素引用；是否继续复制元素，需要按使用场景决定。复制可变对象时，还要考虑其内部引用指向的对象是否也需要隔离。不能仅凭外层对象是新的，或调用了 `clone()`，就认定完成了深拷贝。
