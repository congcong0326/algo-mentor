**重载是在编译期从同名方法中选择适用签名；重写是在继承关系中为继承的实例方法提供实现，调用时可按对象的运行期类型分派。** 一次调用可能先经过重载选择，再经过重写分派，这两个阶段不能合并成“看实际对象选方法”。

重载依靠参数类型、数量或顺序等差异，不能只改返回类型。普通非泛型实例方法的重写要求参数类型一致，返回类型相同或为允许的协变引用类型，访问权限不能收窄，受检异常不能扩大。

## 一个例子同时展示两个阶段

```java
class Parent {
    String describe(Object value) { return "Parent:Object"; }
    String describe(String value) { return "Parent:String"; }
}

class Child extends Parent {
    @Override
    String describe(Object value) { return "Child:Object"; }
}
```

在方法中调用：

```java
Parent receiver = new Child();
Object argument = "算法";
System.out.println(receiver.describe(argument)); // Child:Object
System.out.println(receiver.describe("算法"));   // Parent:String
```

第一行根据实参的编译期类型选 `describe(Object)`，再调用 Child 的重写。第二行先选更具体的 `describe(String)`，Child 没有重写它，所以执行继承来的 Parent 实现。

## 合法重写保留父类型承诺

```java
class Source {
    public Number load() throws java.io.IOException {
        return 1;
    }
}

class IntSource extends Source {
    @Override
    public Integer load() throws java.io.FileNotFoundException {
        return 1;
    }
}
```

`Integer` 是 `Number` 的子类型，受检异常也收窄为 IOException 的子类型。若将访问权限改成 private，或声明更宽的 `throws Exception`，就不能通过编译。基本类型返回值不能靠“更小范围”实现协变，例如 `int` 不能重写为 `short`。

`equals(MyType other)` 只是一个重载，只有匹配 `equals(Object other)` 才能重写 Object 的相等方法。使用 `@Override` 可以尽早发现这类签名错误。

## 重载的常见误判

```java
static void pick(long value) { }
static void pick(Integer value) { }
// pick(1) 选择 long：无需装箱的适用阶段先于装箱阶段。

static void show(String value) { }
static void show(Integer value) { }
// show(null) 编译错误：两个引用类型都适用，但互不更具体。
```

方法调用的适用性分阶段考虑：先不允许装箱和可变参数调用，再允许装箱，最后考虑可变参数。多个候选仍需比较具体程度，不能只记“参数一样就调用最近的方法”。静态同名方法属于隐藏，private 方法和构造器也不属于重写。
