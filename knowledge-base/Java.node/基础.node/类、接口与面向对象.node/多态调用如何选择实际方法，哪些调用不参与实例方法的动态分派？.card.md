**先由编译期类型确定能调用的方法和重载签名，再由接收对象的运行期类型选择该实例方法的重写实现。** 父类或接口类型的引用可以指向子类对象，但不能因此直接调用只在子类中声明的方法。

静态方法按编译期确定的类型选择，字段访问也不参与方法的动态分派；构造器不被重写，private 方法不被子类重写，`super.method()` 显式调用父类一侧的实现。final 实例方法不能被重写，因此没有可供子类替换的实现。

## 同一个引用，三种选择规则

下面类定义放在同一包中，调用片段放在方法内：

```java
class Parent {
    String label = "parent-field";
    String name() { return "parent-method"; }
    static String kind() { return "parent-static"; }
}

class Child extends Parent {
    String label = "child-field";
    @Override String name() { return "child-method"; }
    static String kind() { return "child-static"; }
    String parentName() { return super.name(); }
    void childOnly() { }
}
```

```java
Parent value = new Child();
System.out.println(value.name());                // child-method
System.out.println(value.label);                 // parent-field
System.out.println(value.kind());                // parent-static
System.out.println(((Child) value).parentName()); // parent-method
// value.childOnly(); // 编译错误：Parent 没有这个方法
```

`value.kind()` 虽然允许编译，但容易误导读者；实际代码应写 `Parent.kind()`。字段同名是隐藏，不是重写。向下转型让编译器可以看到子类成员，并不会创建新对象；对象若不是相应子类型，还会发生 `ClassCastException`。

## 重载不会按实参的运行期类型重新选择

```java
class Formatter {
    String format(Object value) { return "Object"; }
    String format(String value) { return "String"; }
}

Object title = "两数之和";
System.out.println(new Formatter().format(title)); // Object
```

`title` 实际引用 String 对象，但表达式的编译期类型是 Object，所以先选 `format(Object)`。如果 Formatter 的子类重写了这一签名，之后才会对这个已选定的签名进行动态分派。

## 构造过程中也可能动态分派

父类构造器调用可重写实例方法时，仍可能进入子类实现。此时子类字段的显式初始化尚未执行，子类方法可能读到默认值。因此不宜在构造器中调用依赖完整子类状态的可重写方法。

面向接口编写业务服务时，多态的价值是让调用点依赖稳定契约、由实现对象提供行为；调用者仍只能使用契约声明的能力。
