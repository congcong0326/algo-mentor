# 内容关系与介绍型总览验证 v0.2

本轮通过 Markdown 验证内容分工，尚未实现产品界面。总览正文、目录与卡片列表、卡片关系分别维护；文档层面可用不等于用户学习效果已被证明。

## 结构如何表达

[目录与卡片入口](navigation.md)维护层级与访问入口：Java 基础下设对象主题，对象下设相等性主题。三篇介绍各自独立成文，父子关系不依赖正文中的链接或“下一篇”段落。

相等性主题直接展示 C04—C07 卡片；对象主题展示 C01—C03；字符串主题尚无介绍正文，但已有 C08，可在列表中直接访问。未完成一个主题的总览不应阻止已有合格卡片独立学习。

卡片具体归属和排序在页面列表中表达，不要求正文逐卡对应。C08 与 C07 的关系表达一个跨主题对比；它不要求把 String 卡复制到对象分支，也不要求相等性介绍提到某张卡片。

## 三种层级的介绍深度

| 介绍 | 应建立的认识 | 需要优先强调的内容 | 留给具体知识点的细节 |
| --- | --- | --- | --- |
| Java 基础 | 语言、对象、标准库、外部交互和扩展能力各解决什么问题 | 类型边界、对象状态、行为契约、失败与资源责任 | 特定 API 用法、代码输出、底层实现 |
| 对象、引用与生命周期 | 对象如何被访问，状态如何建立、共享和比较 | 引用与对象区别、有效状态、修改影响与比较含义 | 初始化顺序、拷贝方式、各个方法或关键字的完整边界 |
| 对象相等与哈希契约 | 为什么需要逻辑相等，哈希为什么依赖它 | 类型语义、规则一致性和键状态稳定性 | equals 的全部约束、计算方式、容器反例与练习 |

概念在父子层级中可以自然重复，但深度不同。判断重复是否必要，应看它是否服务于当前主题的介绍，而不是机械地要求每个术语只能出现一次。

## 介绍能否成为知识上下文

对读者，总览通过共同背景帮助理解问题。例如，先认识“变量指向”和“对象状态”是不同层面的变化，再看到 final 或值传递的问题，就知道它们在辨析什么。介绍提供大概的认识，卡片要求更精确的回答，两者的深度有意不同。

对后续 AI 内容实验，可以使用当前介绍、当前卡的问题及版本，并按需补充前置卡摘要和来源。父级介绍只有在需要更广背景时才加入；层级关系由独立结构提供，不能靠正文是否提到卡片名来推断。

可对同一组 C01—C08 做两组实验：一组仅提供问题与答案，另一组再提供三篇介绍；要求解释每个问题涉及的背景和重要性，并允许一个问题与多个方面有关。检查是否能正确区分变量与对象、相等规则与查找，以及为何稳定状态影响键的使用。不以恢复某一固定卡片顺序作为成功条件。

本轮没有运行模型对照实验，也没有测实际学习收益；介绍文档是背景材料，具体事实和版本边界仍以规范和 API 为准。

## 审查标准与当前状态

| 检查项 | 当前可审查内容 | 验收方式 |
| --- | --- | --- |
| 能否认识当前层级 | 三篇介绍均说明主题范围与用途 | 读者只看正文，能用自己的话解释“这是什么、为什么要了解” |
| 能否理解内容构成 | 正文解释分类、机制与概念之间的关系 | 读者能说出各部分为什么放在一起，而不是只背名词 |
| 是否明确重要性 | 各篇指出优先建立的认识及理由 | 读者能指出关键认识与进一步细节的区别 |
| 正文是否独立 | 三篇介绍无正文内链、卡片清单或阅读指令 | 不提供其他页面也能理解当前介绍；不要求立即掌握卡片答案 |
| 下级是卡片时是否自然 | 相等性介绍与页面上的 C04—C07 列表 | 先读介绍，再看具体问题，观察问题是否能放回背景中理解 |
| 卡片是否独立 | 8 张卡含明确问题、核心回答和来源 | 有基础的读者跳过介绍后仍能理解题意并作答 |
| 导航与关系是否可用 | 独立目录列表及前置/追问/对比关系 | 页面入口可达，前置关系无环；不检查正文是否逐卡引用 |

这些是供本轮用户审查的标准，尚未得到试读结果。不能把“已写出正文”或“链接校验通过”当作学习验收通过。

## 人工试读方法

1. 分别独立展示三篇介绍，不先展示卡片。请读者概括当前主题的用途、主要构成和重点。先观察是否形成整体认识，不考查精确方法契约。
2. 展示目录与卡片列表。请读者挑一个问题，说明它属于刚才背景中的哪一方面，以及自己尚不清楚什么。允许多个合理联系，不要求恢复固定排列。
3. 单独展示相等性介绍，再展示 C04—C07。检查读者是否能理解这些问题为何值得学习；即使不能列出 equals 的全部约束，也不因此判定介绍失败。
4. 给有经验读者直接展示 C02 或 C07。检查条件是否足够明确；需要补基础时，通过卡片的独立前置关系提供帮助。
5. 下一批对异常与资源、泛型与 Stream 重复这个过程，检查其他主题是否也能用介绍建立背景，再扩大正文规模。

记录整体概括、读者指出的重点、问题与背景之间的解释，以及卡片首次回答与查看答案后的变化。页面使用体验、记忆保持、学习计划和复习调度仍待后续测试。
