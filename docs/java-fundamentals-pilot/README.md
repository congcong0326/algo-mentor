先阅读下面三篇总览，检查各自是否讲清主题是什么、为什么有这些内容、各部分如何关联，以及什么最重要。它们的范围逐层收窄，每篇都可以单独阅读。

| [Java 基础总览](overview.md) | 大范围介绍：语言、对象、标准库、外部交互与扩展能力为何构成 Java 基础 |
| [对象、引用与生命周期总览](object-overviews.md) | 主题介绍：访问关系、状态管理、共享和比较为何需要放在一起理解 |

随后查看[目录与卡片入口](navigation.md)，再打开[8 张问题卡](cards.md)。总览读完有大概的认识，看到卡片后才明确具体问题，是本版希望呈现的体验；不要求仅凭总览就能答出所有细节。

## 本版的内容安排

Java 基础总览采用平实的讲述方式，用少量直接相关的例子解释知识之间的联系与学习重点。对象和相等性两篇暂保留 v0.2 文风，供本次比较审查。

三篇总览均重新撰写，去掉围绕题目导入任务的逐步导读，并将对象总览与相等性总览拆为独立文件。各篇保留必要概念解释和简短例子，增加学习重点及其理由。父级解释更广泛的构成，子级解释当前主题，不按卡片逐条组织段落。

[大纲](outline.md)保留 12 个一级主题，每个主题补充了总览应强调的关键认识。大纲中的覆盖范围、候选问题和来源映射用于编辑工作，不是要放进总览正文的章节清单。

目录层级和具体卡片入口集中在 navigation.md；前置、追问与对比关系集中在[验证记录](validation.md)。卡片保留独立的问题、回答和来源，不要求读者先完成某篇总览。总览与卡片即使没有正文内链，也可以通过共同的概念背景和页面结构形成联系。

## 资料与范围

推荐组合仍是：《二哥的 Java 进阶之路》参考中文教学结构，《On Java 8》参考概念解释，JavaGuide 检查问题覆盖，Java 17 官方规范和 API 校验结论。[来源文档](sources.md)记录固定提交、已查阅路径以及每篇介绍的依据。

“Java 基础”在这里指语言、对象模型和常用标准库，默认 Java 17。集合内部实现、并发、JVM 深入机制、Spring 是相邻分支；本轮完成的是 12 主题大纲、三篇介绍和 8 张卡片，其他主题正文仍待编写。

外部资料现位于 Git 忽略的 `knowledge-base/references/` 下：JavaGuide、toBeBetterJavaer、OnJava8 为浅克隆与文本稀疏检出，official 保存官方抽样页面。本版沿用已有快照，按此前要求不做许可筛选。

## 审查时关注的结果

只看介绍时，读者能否认识当前主题及其重要部分；看到卡片时，能否明白具体问题为何属于这个背景，同时发现尚未掌握的细节；跳过介绍时，卡片是否仍然可读、可答。技术检查、人工试读方法和后续 AI 上下文实验的边界见[验证记录](validation.md)。
