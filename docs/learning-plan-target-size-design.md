# AI 学习计划题目规模设计

## 目标

AI 个性化创建不再要求用户填写训练周期和每周投入。用户只选择计划规模：`5`、`10`、`15`、`20`、`25` 或 `30` 题。

## 固定规则

- 默认节奏为每周训练 5 天、每天 1 题；用户在计划保存后可自行调整题包派发节奏。
- 服务端以每 5 题推导 1 个预估周：5-30 题对应 1-6 周。
- AI 按每阶段最多 5 题规划，目标阶段数等于预估周数。
- `targetProblemCount` 是期望规模。题库候选不足、去重或题目事实校验导致无法凑足时，允许少于目标，但不得超过目标；预览同时展示目标数与实际生成数。
- 周数和内部 `weeklyHours` 只为既有节奏、进度和兼容逻辑保留；AI Prompt 不接收它们，也不再以负载容量约束选题。

## 边界

- 模板创建继续沿用模板自带的周期和节奏，不受本设计影响。
- 既有负载模型暂不删除，后续单独评估是否以纯题目数节奏替代。
