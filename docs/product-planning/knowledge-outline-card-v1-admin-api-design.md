# 知识内容管理员接口方案（已撤回）

日期：2026-09-15  
状态：已被 [知识大纲与知识卡片用户侧接口设计](knowledge-outline-card-v1-api-design.md) 替代，不作为实施任务。

当前阶段以用户侧知识库浏览、卡片与文章阅读、四档评价、个人复习中心为核心。共享内容由维护者直接执行数据库导入，不建设管理员 CRUD、内容发布后台或导入 API。

此前提出的管理员创建节点时自动建立 root、管理员写入统一锁 root 等方案不再适用。root 由未来内容导入事务建立；应用启动和用户 GET 不初始化数据。

完整接口清单、参数与返回、可见性、评价事务和导入边界以新的用户侧设计为准。
